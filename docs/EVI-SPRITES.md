# Еві: перша інтеграція спрайтів (Alpha 1.20.0)

## Як працює прототип

Ілюстрації створені у двох листах. **Бойовий лист** має 7 стовпців × 3 рядки
(21 ключова поза), **кінематографічний** має 5 × 2 (10 ключових поз).
Можна використовувати оригінальні PNG або підготовлені WebP із прозорістю.
Кожен лист завантажується з пристрою в меню **Графіка** й кешується у
**IndexedDB** без серверного завантаження. Це тимчасовий художній експеримент,
а не вимога для гри: без листів працює процедурна графіка.

`EviSpriteStates.ts` обирає позу, а `Fighter.ts` лишається джерелом
зіткнень, тривалості атак, руху, оглушення, здоров’я й комбо.

## Бойовий лист 7 × 3

| Кадр | Поза |
|---:|---|
| 0 | нейтральна стійка |
| 1 | альтернативна нейтральна стійка |
| 2 | рух уперед |
| 3 | рух назад |
| 4 | присідання / тимчасово вставання |
| 5 | блок стоячи |
| 6 | блок навприсядки |
| 7 | відрив від землі (майбутній перехід) |
| 8 | стрибок |
| 9 | висока Y та початковий замах дуелі |
| 10 | середня X |
| 11 | нижня B |
| 12 | удар X навприсядки |
| 13 | підсічка / тимчасово перекат |
| 14 | захват |
| 15 | отримання шкоди / захоплений боєць |
| 16 | падіння / нокаут |
| 17 | підготовка спецприйому |
| 18 | удар спецприйому |
| 19 | підготовка SPLASH |
| 20 | виконання SPLASH |

Кожна атака має реальні фази `startup → active → recovery`, але поки
відображає **одну ключову позу**, а не повноцінну покадрову анімацію.

## Кінематографічний лист 5 × 2

- Кадри **0–4**: вступ перед початком матчу, рівно 2 секунди (5 × 0,4 с).
- Кадри **5–9**: переможний жест після **остаточної** перемоги в матчі,
  рівно 2 секунди. Остання поза утримується до нового матчу.

Вступ відбувається **один раз перед першим раундом**, за ним ідуть звичайні
оголошення `ROUND` і `FIGHT!`. У тренуванні вступ пропускається, щоб
не заважати повторювати вправи. Решта персонажів мають процедурну заміну.

## Які спрайти домалювати

**Перший пріоритет, щоб рух не стрибав між ключовими позами:**

1. 4–6 проміжних кадрів для ходьби вперед і назад;
2. окремі фази стрибка, приземлення й падіння;
3. 6–8 кадрів перекату та 4–6 кадрів вставання після нокдауну;
4. реакції на високий/середній/нижній удар, блок і відкидання;
5. для кожної X, Y, B, ↓X, ↓B: кадри підготовки, контакту й відновлення.

**Другий пріоритет, щоб зброя й спецмеханіки відповідали бойовим правилам:**

6. захват: спроба, утримання, перехоплення, кидок, звільнення;
7. дуель: різні X/Y/B та A-захист, CLASH, перемога, поразка;
8. чотири рівні звичайного спецприйому (можна спільну анімацію з різними FX);
9. SPLASH: кидок віяла, його політ/поворот, потрапляння, повернення та
   перебитий замах;
10. проміжні кадри вступу й переможного жесту (поки маємо 5 поз на 2 с).

## Пізніше

Після тесту видно, які пози потребують корекції силуету,
центрування стоп і впізнаваності віяла. Нові аркуші можна імпортувати
без перероблення логіки. Фінальні зображення варто додати в
`public/assets/fighters/evi/` після затвердження анімацій.
